# Weather data

These local widgets use [MET Norway Locationforecast](https://api.met.no/weatherapi/locationforecast/2.0/documentation) first and [wttr.in JSON](https://github.com/chubin/wttr.in#json-output) if MET Norway is unavailable. Forecast values and weather symbols are adapted for compact widget display.

MET Norway data is credited in the widgets and is available under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The local display maps provider symbols to emoji and groups hourly values into daily highs and lows.
