# Виджеты для GNOME Widget Center

Восемь собственных виджетов для расширения GNOME Widget Center. В `widgets/` лежат исходники и настройки по умолчанию, в `settings/` — текущие настройки оформления и погоды.

| Виджет | ID | Размер |
| --- | --- | --- |
| Погода сейчас | `local.weather-current` | 1×1 |
| Погода по часам | `local.weather-hourly` | 2×1 |
| Прогноз на неделю | `local.weather-week` | 2×2 |
| Вероятность осадков | `local.weather-rain` | 1×1 |
| Погодная фраза | `local.weather-quote` | 1×1 |
| Четыре показателя системы | `local.system-four-rings` | 1×1 |
| Тёмный календарь | `local.calendar-dark-grid` | 1×1 |
| Заряд устройств | `local.battery-rings` | 2×1 |

Пять погодных виджетов используют общий модуль `widgets/_blue-weather`. Их файлы `widget-v*.js` и `weather-v*.js` сохранены вместе с текущей версией: GNOME Shell кеширует модули, поэтому имена версий нужны при обновлении.

## Установка

Установите GNOME Widget Center, затем из корня проекта выполните:

```bash
python3 install.py --dry-run
python3 install.py
```

Скрипт обновляет только виджеты из проекта и общий погодный модуль. Существующие настройки пользователя сохраняются; для их замены файлами из `settings/` используйте `python3 install.py --force-settings`. Перед заменой скрипт сохраняет старые файлы в `~/.local/state/gnome-widget-center-widgets/backups/`. После установки выйдите из сеанса GNOME и войдите снова. Положение на рабочем столе при первой установке берётся из `default-position` в `metadata.json`; текущая раскладка всего Widget Center хранится отдельно в `~/.config/gnome-widget-center/layout.json`.

## Заряд устройств

`local.battery-rings` — тёмная карточка 2×1 (368×176 px), четыре фиксированные позиции размером 72 px с иконками и процентами, без названий. Между позициями 12 px, внешние отступы ряда слева и справа одинаковые — 22 px. Свободные позиции обозначаются серыми кольцами-плейсхолдерами (`#48484A`) без иконок и текста. Системная батарея определяется через UPower с резервным чтением `/sys/class/power_supply`: на компьютере без неё кольца ноутбука нет, ИБП и периферия за неё не принимаются. Подключённые Bluetooth-наушники определяются через BlueZ. Заряд берётся из `Battery1`, при необходимости — из соответствующего устройства UPower. При отключении устройства его позиция освобождается, остальные устройства остаются на своих местах; неизвестный заряд обозначается `—`, настоящий нулевой — `0%`.

Если установленный BlueZ и наушники предоставляют отдельные компоненты `left`, `right`, `case`, вместо общего кольца показываются эти компоненты. Виджет самостоятельно не добавляет поддержку фирменных протоколов и не включает экспериментальные функции Bluetooth. Без устройств вместо колец показывается сообщение «Нет подключённых устройств» с иконкой Bluetooth. При зарядке видна молния, при заряде ≤20% кольцо красное. Сигналы системы обновляют данные сразу, резервный опрос по умолчанию выполняется раз в 30 секунд.

Проверка выбора устройств и пограничных случаев: `node --test --test-isolation=none tests/battery-rings.test.mjs` (Node.js 22+).

## Обновление проекта из локальной установки

Если правки внесены через Widget Center или непосредственно в установленный виджет, перенесите их сюда перед коммитом:

```bash
cp -a ~/.local/share/gnome-widget-center/widgets/_blue-weather ~/.local/share/gnome-widget-center/widgets/local.* widgets/
cp -a ~/.config/gnome-widget-center/widgets/local.*.json settings/
git diff --check && git diff
```

В погодных настройках сохранены город и координаты. Проверьте содержимое `settings/` перед публикацией репозитория.
